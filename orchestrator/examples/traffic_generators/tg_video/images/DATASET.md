# Image set for `tg_video`

The folder contains 288 generic images (not specific to any application domain):

- **200 JPEG photographs** (`small_0001.jpg` … `small_0200.jpg`), with the resolutions of
  [PASCAL VOC](http://host.robots.ox.ac.uk/pascal/VOC/) (longest side 500 px) and
  [COCO](https://cocodataset.org) (longest side 640 px) images;
- **88 PNG segmentation masks** with the PASCAL VOC color palette (class labels drawn as flat
  colors).

Sources:
- M. Everingham et al., *The PASCAL Visual Object Classes (VOC) Challenge*, International Journal
  of Computer Vision, 2010.
- T.-Y. Lin et al., *Microsoft COCO: Common Objects in Context*, ECCV 2014.
